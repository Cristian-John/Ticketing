# Shared Component Inventory

This is a lightweight inventory of reusable UI elements available throughout the application.

## Badges (src/styles/components/badges.css)
- Status: .badge-open, .badge-in-progress, .badge-resolved, .badge-closed`n- Severity: .badge-severe, .badge-high, .badge-moderate, .badge-low`n- Metadata: .badge-dept, .badge-cat, .badge-sla`n
## Buttons (src/styles/components/buttons.css)
- .btn: Base button
- .btn-primary: Primary action gradient
- .btn-ghost: Outline/transparent button
- .btn-danger: Destructive action
- .btn-sm: Small button sizing

## Cards (src/styles/components/cards.css)
- .glass-card: Standard frosted glass container
- .stat-card: Dashboard statistic tile
- .panel: Dashboard panel container
- .mini-card: Small ticket preview card

## Forms (src/styles/components/forms.css)
- .form-group: Input wrapper with label spacing
- .input-wrapper: Icon wrapper for inputs
- .custom-checkbox: Styled checkboxes

## Tables (src/styles/components/tables.css)
- .glass-table: Standard data table
- .table-container: Responsive wrapper

## Modals (src/styles/components/modals.css)
- .modal-overlay: Backdrop filter
- .modal: Main modal container
- .modal-header, .modal-body, .modal-actions: Modal structural blocks

## Toast (src/styles/components/toast.css)
- .toast-container: Wrapper for popup messages
- .notif-banner: Full width top banners

## Widgets (src/styles/components/widgets.css)
- .dept-bar-row: Horizontal bar chart rows
- .assignee-list: Checklist widget
- .stars: Rating stars visualization
